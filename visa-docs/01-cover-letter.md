## Tone & content checklist for the cover letter

- [ ] First person · factual · calm
- [ ] No "kindly", no "humbly", no flattery, no emotional language
- [ ] Evidence-based, not promise-based
- [ ] All numbers and dates match every other document in the file
- [ ] Sponsored vs self-funded boundary is stated **once** and consistently
- [ ] One page if possible — two pages absolute maximum
- [ ] Tab numbers in this letter must exactly match the document index
- [ ] **Re-read after filling all placeholders** — every `[bracket]` must be replaced
